# 1min.ai native provider
Add the isolated `oneminai` provider, alias `1min`, from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: a proprietary `UNIFY_CHAT_WITH_AI` POST with an `API-KEY` header and one `promptObject.prompt` string instead of OpenAI `messages`. OpenAI, Responses and Claude inputs are flattened into labeled `System/User/Assistant` lines; unsupported pinned parameters (`tools`, `tool_choice`, `functions`, `function_call`, `response_format`) are not forwarded. Streaming requests use `?isStreaming=true` and map upstream `event: content|done|error` frames into OpenAI SSE chunks; non-streaming replies join `aiRecord.aiRecordDetail.resultObject` strings and report zero usage because the upstream publishes none. Pin ships no artwork asset, so `web/public/providers/oneminai.png` is a 128x128 glyph generated from pinned `textIcon "1M"` and `#6366F1`. Verification: offline prompt/error and request fixtures pin the payload, header, path and parameter filtering, plus frontend metadata/model/glyph assertions. No live provider, login or quota validation was performed.
