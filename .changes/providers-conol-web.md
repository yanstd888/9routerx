# Conol web-chat native provider
Add the isolated `conol-web` provider, alias `cnl`, from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: the experimental session-cookie chat lane on `/api/sessions`. The executor normalizes the `__Secure-better-auth.session_token` cookie, creates an empty session, pins preset → model → effort in that order, submits the latest user turn, then polls cumulative NDJSON updates until the `done` event and folds staged/assistant/stream text into OpenAI frames. Model suffix effort is clamped onto the pinned per-model ladder. Image upload and persisted session bindings are deliberately not fabricated. Pin ships no artwork asset, so `web/public/providers/conol-web.png` is a 128x128 glyph generated from pinned `textIcon "CO"` and `#F6C945`. Verification: offline session/model/submit/stream fixtures and frontend fallback-model/glyph assertions. No live provider, login or quota validation was performed.
