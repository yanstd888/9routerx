# Keenable web search/fetch provider
Add the isolated `keenable` provider from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: public and optional-keyed web search/fetch routes on `https://api.keenable.ai`. The registry declares no chat model; it carries the API-key and public fetch/search URLs, GET/POST methods and the mandatory `X-Keenable-Title` header. Go helpers pin the public/keyed route split and URL encoding for fetch targets and search queries; the key only lifts per-IP rate limits and is never sent to the public routes. Pin ships no artwork asset, so `web/public/providers/keenable.png` is a 128x128 glyph from the provider's `KE` mark and `#06B6D4`. Verification: offline route-split fixtures and frontend metadata/artwork assertions. No live provider, login or quota validation was performed.
