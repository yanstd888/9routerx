# GigaChat token-exchange native provider
Add the isolated `gigachat` provider from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: the OpenAI-compatible chat lane on `https://gigachat.devices.sberbank.ru/api/v1` that requires a short-lived Bearer token. The stored Basic credential is exchanged at the pinned Sber OAuth endpoint with `scope=GIGACHAT_API_PERS`, a fresh `RqUID` per exchange and a form body, and the resulting `access_token`/`tok` is cached by credential hash until 60 seconds before expiry; a supplied fresh access token is reused. Only the Bearer token is sent to the chat endpoint — the Basic key never leaves the token exchange. Scope and auth URL may be overridden per connection. Pin ships no artwork asset, so `web/public/providers/gigachat.png` is a 128x128 glyph generated from pinned `textIcon "GC"` and `#10B981`. Verification: offline httptest fixtures pin Basic/form/RqUID token exchange, Bearer chat auth and cache reuse across two requests, plus frontend metadata/catalog/glyph assertions. No live provider, login or quota validation was performed.
