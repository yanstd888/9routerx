# Cerebrium deployment native provider
Add the isolated `cerebrium` provider from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: a Bearer-authenticated OpenAI-compatible lane whose connection Base URL must be the deployment's own `/run` endpoint (`https://api.cerebrium.ai/v4/<project-id>/<app-name>/run`). A request without that URL is refused with 400 before any body is built or sent, so a configuration error never trips provider cooldown or circuit breaker; with a URL present the shared OpenAI forwarder handles chat, Responses and stream translation. The pinned static catalog contains one chat model, `meta-llama/Meta-Llama-3.1-8B-Instruct`. Pin ships no artwork asset, so `web/public/providers/cerebrium.png` is a 128x128 glyph generated only from pinned `textIcon "CB"` and `#EB3A6F`. Verification: offline httptest fixtures pin the missing-URL 400, exact deployment path, Bearer auth, body passthrough and reply, plus frontend registry/model/glyph assertions. No live provider, login or quota validation was performed.
