# SYNTX.ai native provider
Add the isolated `syntx` provider, alias `stx`, from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: the unofficial Bearer-JWT chat lane using create-chat, generate and stream URLs. OpenAI messages are flattened into labeled text; the pinned fallback catalog provides 34 models and their `ai_name`/thinking flags. The executor creates a text chat, posts the generate body with `chat_uuid`, `model`, `thinking` and native tools disabled, validates the returned stream host against the pinned SSE origin or the configured host, then folds `content` and `usage_final` events into OpenAI SSE/completion frames. Image upload, session rollover and native tool execution are deliberately not fabricated. Pin ships no artwork asset, so `web/public/providers/syntx.png` is a 128x128 glyph generated from pinned `textIcon "SX"` and `#FF4D00`. Verification: offline create/generate/stream fixtures and frontend metadata/catalog/glyph assertions. No live provider, login or quota validation was performed.
