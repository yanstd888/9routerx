# Ideogram native image API
Add the isolated `ideogram` API-key image provider from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`, with alias `ideo` and the two curated models `V_3` and `V_2A`. The native media lane POSTs to the pinned image endpoint `https://api.ideogram.ai/generate` (stored as `ImageURL`; the catalog `BaseURL` is the bare API root) with `Content-Type: application/json`, an `Api-Key` header and only `prompt`, `aspect_ratio: ASPECT_16_9` and `model` (default `V_3`); non-2xx upstream status and raw text are preserved, empty results answer 502, and the first returned URL is downloaded under a 25MiB/60s cap before being emitted as an OpenAI image with `b64_json`.
