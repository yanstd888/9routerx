# NLP Cloud native provider
Add the isolated `nlpcloud` provider, alias `nlpc`, from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: the proprietary chatbot API on `https://api.nlpcloud.io/v1/gpu/<model>/chatbot` with `Authorization: Token <key>`, not a generic OpenAI chat lane. OpenAI messages are converted into last-user `input`, joined system/developer `context` and prior user/assistant `history` pairs, with temperature and top_p preserved; temperature/top_p keys not supplied are omitted. Responses and Claude clients are translated to the chat shape before conversion. Upstream JSON `response` is folded into an OpenAI completion with bounded, estimated usage; upstream SSE deltas and JSON-only streaming replies are folded into OpenAI SSE chunks before the router's Responses/Claude bridges run. Connection base URLs normalize away an already-included model/chatbot suffix. Pin ships no artwork asset, so `web/public/providers/nlpcloud.png` is a 128x128/2867B glyph generated only from pinned `textIcon "NLPC"` and `#2196F3`. Verification: offline httptest fixtures pin Token auth, endpoint path, input/context/history payload, SSE delta translation, base normalization and frontend metadata/catalog/artwork assertions. No live provider, login or quota validation was performed.
