# Naver CLOVA Studio native provider
Add the isolated `clova-studio` provider, alias `clova`, from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: the native Chat Completions v3 endpoint `https://clovastudio.stream.ntruss.com/v3/chat-completions/<model>` with a Bearer Naver Cloud Platform key, not the OpenAI compatibility shim. OpenAI requests are translated into CLOVA messages, sampling fields, reasoning `thinking.effort`, output caps (`maxCompletionTokens` for HCX-007, `maxTokens` elsewhere), HCX-005 image parts and tool mode with its 1024-token floor; tool mode and thinking are mutually exclusive as upstream requires. CLOVA always streams upstream, so token, reasoning and tool frames are folded into OpenAI SSE chunks and accumulated into one completion for non-streaming clients, with the result snapshot emitted only when no tokens were streamed. Pin ships no artwork asset, so `web/public/providers/clova-studio.png` is a 128x128 glyph generated from pinned `textIcon "CS"` and `#03C75A`. Verification: offline payload/stream fixtures and frontend metadata, catalog and artwork assertions. No live provider, login or quota validation was performed.
