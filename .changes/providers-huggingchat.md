# HuggingChat session-cookie native provider
Add the isolated `huggingchat` provider from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: the free Hugging Face chat lane on a session cookie. The executor normalizes the cookie, creates a `/chat/conversation` with the selected model and optional system `preprompt`, reads `rootMessageId` from `/chat/api/v2/conversations/{id}`, merges refreshed `Set-Cookie` values, then posts a multipart `data` envelope (`inputs`, `is_retry`, `is_continue`, `generationId`, MCP lists, `timezone`, `id`). The JSONL reply's `stream`, `reasoning`, `finalAnswer` and terminal `status` events are folded into OpenAI SSE chunks and a single non-streaming completion; `finalAnswer` is suppressed when tokens already streamed to prevent duplication. Tool-call events are not fabricated. Pin ships a genuine SVG, rasterized to the task's 128px PNG.
