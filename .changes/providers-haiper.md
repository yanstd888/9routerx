# Haiper image and video native provider
Add the isolated `haiper` provider, alias `hp`, from OmniRoute pin `632d84f569f72893ed148e5b19dd05e2fff1a52a`: `HAIPER_KEY` job submission on `/v1/jobs/gen2/text2image` and `/v1/jobs/gen2/text2video` with bounded `/v1/jobs/{job_id}` polling. Image requests send the prompt and an aspect ratio (default `16:9`); video requests pin duration 4 and `16:9`. Terminal `completed`/`succeeded` jobs download `creation_url` or the nested image/video URL through the router's guarded, bounded media downloader and return OpenAI-shaped `{created,data:[{b64_json,format}]}` with `png` or `mp4`. A 300-second deadline, 5-second poll and explicit failed-job status prevent an unbounded wait. Pin ships no artwork asset, so `web/public/providers/haiper.png` is a 128x128 glyph generated from pinned `textIcon "HP"` and `#6366F1`. Verification: offline endpoint, status-header and SSRF-guard fixtures, plus frontend registry/model/glyph assertions. No live provider, login or quota validation was performed.
